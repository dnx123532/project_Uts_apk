🎬 Tixio – Seed Firestore

👑 Setup Admin

Masukkan UID akun yang ingin dijadikan admin.
Cari di Firebase Console → Authentication → klik akun → salin User UID.

🗑️ Hapus Semua Film

Hapus semua dokumen di koleksi movies (termasuk data lama dengan path assets/images/).
Lakukan ini sebelum seed ulang agar tidak ada duplikat.

Klik tombol di bawah untuk mengisi data Food Items dan Cinemas ke Firestore.
